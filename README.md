# 🥗 F.R.E.S.H Platform
### **Food Rescue – ESG – Smart Hyperlocal**

<img src="https://files.catbox.moe/ku0gzy.png" alt="QTusdev">

**F.R.E.S.H** là một hệ sinh thái Logistics & ESG thế hệ mới, vận hành bằng trí tuệ nhân tạo (Enterprise AI) nhằm giải quyết vấn đề lãng phí thực phẩm toàn cầu bằng cách kết nối hàng tồn dư với nhu cầu người dùng trong thời gian thực tại địa phương.

---

## 🚀 Key Portals

Hệ thống được chia thành 3 phân hệ chính với giao diện chuyên biệt:

1.  **Consumer App (Người dùng)**:
    *   Săn các ưu đãi thực phẩm sắp hết hạn (Flash Deals) trên bản đồ thời gian thực.
    *   Theo dõi chỉ số dinh dưỡng AI & Tín chỉ Xanh (Green Credits).
    *   Tối ưu chi phí sinh hoạt đồng thời bảo vệ môi trường.

2.  **Merchant Hub (Đối tác)**:
    *   Quản lý kho hàng thông minh với AI nhận diện hạn sử dụng.
    *   **AI Dynamic Pricing**: Tự động điều chỉnh giá theo thời gian thực để tối đa hóa khả năng cứu thực phẩm.
    *   Quản lý tài chính, ví điện tử và báo cáo doanh thu.

3.  **Enterprise Admin (Quản trị)**:
    *   Giám sát toàn bộ mạng lưới Logistics hyperlocal.
    *   **AI Fraud Monitoring**: Hệ thống phát hiện gian lận và hành vi bất thường.
    *   Báo cáo dữ liệu ESG (Environmental, Social, and Governance) cho doanh nghiệp.

## 🛠 Tech Stack

Dự án được xây dựng trên nền tảng công nghệ hiện đại nhất 2025-2026:

*   **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (CSS-first engine)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/) & [React Three Fiber](https://r3f.docs.pmnd.rs/) (3D Background)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **State Management**: Custom React Context with LocalStorage persistence.
*   **Internationalization**: Custom i18n engine (VN/EN supported).

## 💎 Features & Aesthetics

*   **Premium UI/UX**: Thiết kế theo phong cách hiện đại (Modern Enterprise), sử dụng bảng màu Slate & Emerald sang trọng.
*   **Dark Mode Sync**: Hỗ trợ chế độ sáng/tối đồng bộ toàn hệ thống, khử hiện tượng nháy trắng khi tải trang.
*   **Global Settings**: Widget nổi cho phép thay đổi ngôn ngữ và giao diện tức thì ở bất kỳ đâu.
*   **AI Assistant**: Trợ lý AI tích hợp (Floating AI) sẵn sàng hỗ trợ người dùng và đối tác 24/7.
*   **Responsive**: Tối ưu hóa 100% cho các thiết bị di động với thanh điều hướng thông minh.

## ⚙️ Installation & Development

### Prerequisites
*   Node.js 20+
*   NPM / PNPM / Bun

### Setup
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd f.r.e.s.h
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

```bash
http://localhost:3000/customer
http://localhost:3000/partner
http://localhost:3000/admin
```
